# StudyReco

学習の「記録」ではなく、  
**学習行動を継続させる体験設計**を目的とした個人開発Webアプリ。

⬇️

記録すること自体が作業（コスト）になり、継続を阻害するという課題を、『計測と記録の完全同期』と『AIフィードバック』によって解決しました。

✏️
「行動と報酬の距離を最小化する設計」をテーマに改善を重ねています。

---

## 💡 課題

既存の学習記録アプリでは、

- 記録のために「日付・科目・時間」の入力が必要
- 入力自体が負担となり継続を阻害
- 記録後のフィードバックが弱く、達成感が得られない

という問題があり、学習習慣の定着に繋がりにくい状態でした。

---

## 🔍 仮説

継続できない原因は以下にあると仮定しました。

- 入力コストが高い
- 行動後の報酬（フィードバック）が弱い

そのため、**行動と報酬の距離を最小化することで継続率が向上する**と考えました。

---

## 🚀 解決アプローチ

「記録する」ではなく、  
**学習行動そのものが記録になる体験設計**へ転換。

- タイマー計測による自動記録（手入力ゼロ）
- 記録直後にAIフィードバックを生成
- カレンダーと週次リストを連動させた振り返り機能

---

## 🛠 主な機能

### 1. タイマー計測型 学習記録
- Date.now() による差分計算で高精度な計測
- Screen Wake Lock API によるスリープ防止
- localStorage による状態保持

👉 入力ではなく「行動」に紐づく記録体験を実現

---

### 2. 秒単位データ管理による整合性設計
- データはすべて秒（Integer）で統一
- 表示時のみ HH:MM:SS に変換
- データ層と表示層を分離

👉 計算誤差・整合性問題を解消

---

### 3. 状態の一元管理（State Lifting Up）
- currentDate を App.tsx に集約
- 月次・週次データの整合性を担保

👉 Single Source of Truth を実現

---

### 4. AI学習アドバイザー
- 記録保存をトリガーにGemini APIを実行
- 学習内容に応じたフィードバックを即時生成

👉 行動直後に報酬を設計し、継続を促進

---

## 🔄 改善事例（設計変更）

### ■ NaN問題の解決

**問題：**
学習時間を分（Float）で管理していたため、計算誤差により NaN が発生

**原因：**
秒と分の二重管理によるデータ不整合

**対応：**
データを秒（Integer）に統一する設計へ刷新

**結果：**
- 計算誤差の排除
- 表示・集計の整合性向上
- バグの根本解消

## 🏗 アーキテクチャ

フロントエンドにロジックを集約し、Firebaseを活用したサーバーレス構成。

```
┌─────────────────────────────────────────────────────────────┐
│                     ブラウザ（Firebase Hosting）              │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                    App.tsx（Root）                    │   │
│  │  - 全体の state 管理（records, user, currentDate）    │   │
│  │  - Firebase Auth / Firestore の CRUD                 │   │
│  │  - AI呼び出し (fetchAiComment)                       │   │
│  │  - フィルタリング（月次 / 週次）                      │   │
│  └──────────────┬───────────────────────────────────────┘   │
│                 │ Props（データ + コールバック）              │
│     ┌───────────┼──────────────────────────────────┐        │
│     ▼           ▼                    ▼              ▼        │
│  HeaderWithForm  Monthly          Ranking        AIComment  │
│  ├─ Header       ├─ カレンダー     ├─ 科目別       └─ ロボ   │
│  └─ StudyForm    └─ 月次統計       └─ 集計ランキング          │
│     └─ Timer                                                │
│                  BarChart         StudyList                 │
│                  └─ 週次棒グラフ   └─ StudyItem（編集/削除）  │
│                                                             │
└──────────────────────────┬──────────────────────────────────┘
                           │ HTTP / Firebase SDK
        ┌──────────────────┼─────────────────┐
        ▼                  ▼                 ▼
  Firebase Auth      Firestore          Gemini API
  (Google OAuth)   (records コレクション)  (REST)
        │
  localStorage
  (タイマー永続化)
```

## 🛠 使用技術

### フロントエンド
- React 19.2.0: コンポーネント指向によるUI開発
- TypeScript 5.9.3: インターフェース定義による型安全性の担保
- Vite 7.2.4: 高速なHMRとビルドサイクルの実現
- CSS Modules: スコープ付きCSSによるスタイルの衝突防止
- ApexCharts: 学習データの動的な可視化

### バックエンド / インフラ
- Firebase (Auth / Firestore / Hosting): 認証、DB、ホスティングの一元管理
- Gemini 2.5 Flash API: AI学習アドバイスの生成
- Screen Wake Lock API: 計測中の画面スリープ防止

### 可視化 / 外部API
- ApexCharts
- Gemini API

### Web API
- Screen Wake Lock API
